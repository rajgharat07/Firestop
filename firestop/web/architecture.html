Architecture

One graph. Four planes. Object-store native.

Firestop is a Python client + FastAPI UI over HydraDB. Hydra runs as a separate AGPL service — we never vendor its source. Durable state lives in MinIO; the indexer keeps multi-hop traversals fast.

Topology

MinIO · graph-node · indexer

MinIO S3-compatible store
ports 9000 / 9001
graph-node OpenCypher HTTP + Bolt
HTTP 8443 · Bolt 7687
graph-indexer Immutable CSC generations
admin 9091

Writes go over HTTP batched UNWIND. Bolt is used as a connectivity check in firestop doctor.

Edges

  • VERSION_OFrelease → package
  • DEPENDS_ONruntime · temporal
  • DEV_DEPENDS_ONbuild-time
  • USES_LOCKFILE / PINSservice → pin
  • AFFECTSadvisory → release
  • CAN_PUBLISH / PUBLISHEDmaintainer

Runtime vs build-time is two relationship types, not a property — path procedures cannot filter on rel properties. As-of filtering is applied client-side after paths return.
